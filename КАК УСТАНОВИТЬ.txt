РУЛЕТКА РЕЧИ — установка на iPhone

1. Залей сайт (один раз, с компьютера)
   - Зайди на github.com, создай аккаунт, если его нет.
   - New repository → имя, например, ruletka → Public → Create repository.
   - Нажми «uploading an existing file» и перетащи ВСЁ содержимое этой папки
     (index.html, sw.js, manifest.webmanifest и папку icons) → Commit changes.
   - Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
   - Через минуту-две сайт будет по адресу https://ТВОЙ-НИК.github.io/ruletka/

2. Поставь на телефон
   - Открой этот адрес на iPhone именно в Safari.
   - Кнопка «Поделиться» → «На экран «Домой»» → «Добавить».
   - Иконка появится рядом с остальными приложениями, открывается во весь экран,
     после первого запуска работает и без интернета.

Обновить приложение: замени index.html в репозитории на новый и перезапусти иконку.
Темы, настройки и прогресс хранятся на самом телефоне.
